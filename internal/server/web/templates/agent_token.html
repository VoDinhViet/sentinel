Connect the server

On {{.Data.Agent.Name}}, add the token to /etc/sentinel/sentinel.env:

SENTINEL_TOKEN={{.Data.Token}}

and this to /etc/sentinel/config.yaml:

server_name: {{.Data.Agent.Name}}
central:
  url: {{.Data.PublicURL}}
  token: "${SENTINEL_TOKEN}"
  managed: true   # edit backups, monitoring and uptime checks from this UI

Then sudo systemctl restart sentinel. The server appears as online within a minute. With managed: true, the server's current config is uploaded the first time it connects.
